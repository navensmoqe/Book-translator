# PDF Arabic Translator — Android

تطبيق شخصي لترجمة ملفات PDF إلى العربية مع:

- إضافة عدد مفتوح عمليًا من مفاتيح **Groq** و **OpenRouter**.
- دعم أي API متوافق مع OpenAI عبر خيار **Custom**.
- تبديل تلقائي إلى المفتاح التالي عند Rate Limit (HTTP 429) أو أخطاء الخادم.
- حفظ مفاتيح API محليًا في **Flutter Secure Storage** بدون قاعدة بيانات أو تسجيل دخول.
- اختيار PDF من الهاتف.
- OCR محلي باستخدام Google ML Kit للنصوص اللاتينية.
- الحفاظ على الصور وترتيب الصفحة بصريًا عبر استخدام الصفحة الأصلية كخلفية.
- إنشاء PDF عربي وحفظه في `Downloads/PDF-Arabic-Translator`.
- بناء APK تلقائيًا من GitHub Actions.

## ملاحظة مهمة حول التنسيق

هذه النسخة الأولى تحفظ الصفحة الأصلية كصورة ثم تغطي مناطق النص المكتشف وتكتب العربية فوقها. لذلك الصور وترتيب الصفحة يبقيان قريبين جدًا من الأصل، لكن الخلفيات الملونة أو التصاميم المعقدة قد يظهر فوقها مستطيل أبيض مكان النص. ليست إعادة بناء متجهية 100% للـPDF.

## بناء APK من الهاتف عبر GitHub

1. أنشئ Repository جديدًا على GitHub، ويفضل Public إذا أردت الاستفادة من GitHub Actions بدون استهلاك دقائق المستودعات الخاصة.
2. ارفع محتويات هذا المشروع إلى المستودع، بحيث يظهر مجلد `.github` أيضًا.
3. افتح تبويب **Actions**.
4. اختر **Build Android APK**.
5. اضغط **Run workflow**، أو فقط اعمل Push إلى `main`.
6. بعد نجاح البناء افتح الـRun وانزل إلى **Artifacts**.
7. نزّل `PDF-Arabic-Translator-APK` ثم فك الضغط وثبّت `app-release.apk` على أندرويد.

## إعداد API داخل التطبيق

افتح أيقونة المفتاح ثم **إضافة API**.

### Groq
- Provider: `Groq`
- Base URL: `https://api.groq.com/openai/v1`
- Model الافتراضي: `openai/gpt-oss-120b`
- ضع مفتاح `gsk_...`

### OpenRouter
- Provider: `OpenRouter`
- Base URL: `https://openrouter.ai/api/v1`
- Model الافتراضي: `openrouter/free`
- ضع مفتاح `sk-or-...`

يمكنك إضافة أكثر من مفتاح من نفس المزود. عند 429 ينتقل التطبيق للمفتاح التالي تلقائيًا.

## الخصوصية

مفتاح API لا يوضع في GitHub ولا في الكود. يتم إدخاله بعد تثبيت APK ويُحفظ محليًا بواسطة `flutter_secure_storage`.

## حدود النسخة الأولى

- OCR الافتراضي مضبوط على الحروف اللاتينية، لذلك هو أفضل حاليًا للإنجليزية واللغات اللاتينية إلى العربية.
- ملفات PDF الكبيرة جدًا قد تستهلك ذاكرة كبيرة لأن الصفحات تُحوّل إلى صور داخل ملف الإخراج.
- النص فوق خلفيات غير بيضاء قد لا يندمج بصريًا بشكل مثالي.
- بعض نماذج OpenRouter المجانية قد لا تلتزم دائمًا بإخراج JSON؛ التطبيق يحاول التعامل مع ذلك ويبدل API عند فشل الطلب.
